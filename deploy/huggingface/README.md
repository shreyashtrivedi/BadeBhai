# BadeBhai: live demo

Ask questions about **psf/requests** and **sindresorhus/ky**. BadeBhai plans, searches the code, git
history, GitHub issues and docs, grades its own evidence, and answers with citations that are checked
against the real files and commits.

This public demo has fixed repositories and a per-visitor question limit. To use it on any repository
(including private ones), entirely on your own machine and for free, see the source:
**https://github.com/shreyashtrivedi/BadeBhai**
